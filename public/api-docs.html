Developer API

Build against the market.

The Not An Insider API exposes markets, identity status, trade execution, balances and the tamper-evident enforcement audit trail.

API principle
Authorization is evaluated for every trade. A valid account session does not by itself authorize a market transaction.

Base URL

https://not-an-insider-just-lucky.biz/api/v1

Market agent

ans://v1.0.0.not-an-insider-just-lucky.biz
Execution

Every trade passes six gates.

The trade endpoint fails closed. Funds move only after all mandatory enforcement checks succeed.

01 · Signature Verify the signed canonical trade payload.
02 · Nonce Reject replayed transaction nonces.
03 · ANS Validate live agent status and identity.
04 · Solvency Confirm sufficient available funds.
05 · Affiliation Compare affiliations against market restrictions.
06 · Timing Flag trades near declared material events.
Enforcement

Decision states

Decision Meaning Money moves
ALLOWED All enforcement gates passed. Yes
FLAGGED Trade passed but triggered a timing flag. Yes
BLOCKED One or more mandatory gates failed. No
Markets

Market endpoints

GET /markets

Returns active prediction markets and their current state.

GET /markets/:marketId

Returns one market, including outcome pricing, restricted affiliations and material-event metadata.

Transactions

Trade endpoints

POST /trades/preview

Calculates the expected position before execution. No funds move.

GET /trades/:tradeId

Returns the current state of a transaction.

{ "tradeId": "trade_8f31", "decision": "ALLOWED", "marketId": "vt-next-game", "outcome": "YES", "amount": 25.00, "status": "OPEN" }
Accountability

Audit endpoints

Enforcement decisions are appended to a hash-chained audit history.

GET /audit

Returns enforcement decisions in chain order.

GET /audit/:tradeId

Returns the audit record associated with a trade.

{ "tradeId": "trade_8f31", "decision": "ALLOWED", "reasons": [ "SIGNATURE_VALID", "NONCE_VALID", "ANS_ACTIVE", "SOLVENT", "NO_RESTRICTED_AFFILIATION" ], "flagged": false, "timestamp": "2026-09-19T20:35:12Z", "previousHash": "3fa8...", "hash": "71bd..." }
GET /audit/verify

Recomputes the audit chain and reports whether its historical records remain internally consistent.

{ "valid": true, "entries": 1842, "brokenAt": null }

Timing

Material events

GET /markets/:marketId/material-event

Returns the declared material-event timestamp and applicable timing window.

POST /markets/:marketId/material-event

Administrative endpoint for timestamping a known material event.

Administrative authorization is required. This endpoint cannot bypass identity, signature, nonce, balance or affiliation enforcement.
Cryptography

Trade signatures

Clients sign the canonical trade payload before submission. Private signing keys remain client-side.

Canonical field order

tradeId agentId marketId outcome amount nonce timestamp

Algorithm

RSA-SHA256
Replay protection

Every trade requires a unique nonce.

A nonce may be consumed once. Reusing a previously accepted nonce causes the transaction to fail before funds move.

{ "decision": "BLOCKED", "code": "NONCE_REPLAY", "tradeId": "trade_8f31" }
Responses

Enforcement errors

Code Meaning
SIGNATURE_INVALID Trade signature could not be verified.
NONCE_REPLAY The supplied nonce has already been consumed.
ANS_INACTIVE The trader's ANS registration is not active.
PUBLIC_KEY_MISMATCH Registry key does not match the expected identity key.
INSUFFICIENT_FUNDS The account cannot fund the requested trade.
AFFILIATION_RESTRICTED The trader has an affiliation restricted by this market.
MATERIAL_EVENT_FLAG The trade occurred within a declared timing window.
