Connected API.

GET /api/markets — persistent market pools and resolution status.

GET /api/agents — provisioned public identities (never private keys).

GET /api/audit?after=0 — ascending audit cursor, reasons, hash integrity.

GET /api/payments — pending, settled, and review states.

GET /api/status — configuration readiness, no secret values.

POST /api/trades — signed tradeId, agentId, marketId, outcome, amount, nonce, timestamp, signature.

Admin POST routes require x-demo-key: /api/admin/agents, /api/admin/material-event, /api/admin/reconcile, /api/admin/resolve, /api/admin/payouts.

Signing: RSA-SHA256 or ECDSA P-256/SHA-256 (64-byte P1363), chosen by the ANS certificate key. Canonical JSON field order: tradeId, agentId, marketId, outcome, amount, nonce, timestamp.

Sandbox transfers are not real-world money. A queued/pending transfer is never reported as settled. Resolution splits the pool in cents among winners; no winners means refunds.
