Banking flow

What happens here?

The banking layer supplies financial state. It does not decide whether a user is permitted to trade.

1
Connect

Create or retrieve the linked sandbox account.

2
Read balance

Profile and checkout display one shared balance.

3
Clear trade

Identity and market rules are checked before funds move.

4
Transfer

Approved trades debit the linked balance.

5
Settle

Winning positions eventually credit payouts back.

Security

Banking stays isolated.

When the real Nessie connection is added, API credentials should remain on the server. The browser should only receive the account information it needs to display.
